# Repository skills

Inspect applicable repository instructions and the relevant `.agents/skills/<name>/SKILL.md` before matching work. These are repository-local technical workflows, not permissions or standing authorizations. Select skills by relevance; all are not invoked on every task. Source pins, licenses, provenance and adaptations are recorded in each skill's `source.json`; review upstream changes before deliberate updates.

- [web-design-guidelines](.agents/skills/web-design-guidelines/SKILL.md): accessibility, interaction and responsive review of the React/Vite client.
- [react-best-practices](.agents/skills/react-best-practices/SKILL.md): client-side React performance and rendering guidance.
- [composition-patterns](.agents/skills/composition-patterns/SKILL.md): reusable component APIs, variants and shared state.
- [business-app-ui-design](.agents/skills/business-app-ui-design/SKILL.md): dashboards, tables, filters, forms and UI states using existing patterns.
- [code-apps-foundation](.agents/skills/code-apps-foundation/SKILL.md): conditional only for an explicitly scoped future Power Apps Code App migration/integration; TicketManager is not a Code App.
- [typed-mocks-and-fixtures](.agents/skills/typed-mocks-and-fixtures/SKILL.md): deterministic synthetic data matching shared DTOs and existing service seams.
- [platform-compatibility-review](.agents/skills/platform-compatibility-review/SKILL.md): conditional only for explicit Power Apps Code App work; no Power Platform dependency or architecture is present.
